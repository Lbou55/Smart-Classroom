System Overview

The Smart Classroom system collects real‑time temperature, humidity, motion, and occupancy data from an ESP32. The Flask backend stores readings in Firebase, uses an ML model to predict temperature 10 minutes ahead, and automatically controls the AC (or allows manual override). A web dashboard displays live data and statistics.
